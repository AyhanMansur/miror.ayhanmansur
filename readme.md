## 🌟 About

**miror.ayhanmansur** is a lightweight, always-available mirror built for Iranian users who need quick access to networking and VPN tunnel installation scripts — without the hassle of blocked domains or slow connections.

⚡ **Zero setup. No VPS required.**
Everything runs on **GitHub Pages** — fast, free, and reliably worldwide.

## ⚡ Quick Usage

**Run any script directly from the mirror:**

</div>

```bash
bash <(curl -Ls https://ayhanmansur.github.io/miror.ayhanmansur/xui-install.sh)
```

<div align="center">

**Or download it first, then run:**

</div>

```bash
curl -LO https://ayhanmansur.github.io/miror.ayhanmansur/xui-install.sh
bash xui-install.sh
```

Every file's checksum is listed in **[`SHA256SUMS`](https://ayhanmansur.github.io/miror.ayhanmansur/SHA256SUMS)**.

</div>
